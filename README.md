# 100allora.it

Personal site, built with [Zensical](https://zensical.org) from `docs/` and
deployed to GitHub Pages by `.github/workflows/pages.yml`.

```sh
uv run zensical serve   # preview at http://localhost:8000
uv run zensical build   # output in site/
lychee site             # link check (config in lychee.toml)
```

## Paths owned by other repositories

These are served from 100allora.it by their own GitHub Pages sites. Don't add
pages here at the same paths.
